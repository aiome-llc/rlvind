# RLVIND

**Reinforcement Learning with Verifiable Inverse Nonlinear Dynamics**

Train a model to make other models better. RLVIND proposes an RL gym for neural network training, evaluation, and
direct weight programming, with progressively harder tasks and rewards from measured results.

The immediate objective is to improve unfamiliar neural systems. The longer-term hypotheses are recursive
self-improvement and transfer to understanding nonlinear systems in biology, chemistry, and physics.

- [Proposal](docs/proposal.md): motivation, curriculum, first experiment, and longer-term hypotheses.
- [Training gym design](docs/training-gym.md): initial environments, episode protocol, rewards, and evaluation.
